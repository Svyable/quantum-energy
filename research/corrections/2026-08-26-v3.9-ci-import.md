# Corrections — v3.9 publication CI gate

## Correction 1 — dynamic-import test harness

### Error

The first execution of the new v3.9 publication CI gate failed in all six matrix jobs before any scientific calculation ran. The helper in `tests/reproducibility_gate.py` created a module with `importlib.util.module_from_spec()` and executed it without first registering the module in `sys.modules`.

The imported v3.8 benchmark defines a `@dataclass`. Python's dataclass runtime introspection expects the executing module to be present in `sys.modules`, as it is during a normal import. The custom loader violated that expectation and raised:

`AttributeError: 'NoneType' object has no attribute '__dict__'`

### Impact

- No v3.7 or v3.8 numerical result failed.
- The failure occurred in newly introduced CI-loader infrastructure before the benchmark calculation or raw-spectrum self-tests executed.
- No physical claim or published calculation was superseded.

### Correction

`load_module()` now inserts the module into `sys.modules` before `exec_module()`, and removes it again if execution raises. This mirrors normal Python import semantics.

### Provenance

Failing GitHub Actions run: `scientific-reproducibility` run `33003278831`.

## Correction 2 — false-precision SI cross-check tolerance

### Error

After correcting the loader, the independent SI cross-check failed because its initial absolute agreement tolerance was set to `2e-15 V`. For PM6:Y6 the two implementations gave:

- exact-SI path: `0.2504638987532138 V`
- committed eV/K path: `0.2504638987532087 V`

Difference: approximately `5.16e-15 V`.

This difference is not a physical or algorithmic discrepancy. It is explained by decimal representation of the primary constant:

- exact SI ratio `k_B/q = 8.617333262145179e-5 V/K`;
- committed primary constant `8.617333262145e-5 eV/K`.

The relative difference in the constants is about `2.08e-14`, so demanding 2 fV agreement was unjustified false precision.

### Impact

- The published v3.8 benchmark remains unchanged to every physically relevant digit.
- The discrepancy is roughly eleven orders of magnitude below the program's 10–20 mV mechanism target and far below source-data rounding/experimental uncertainty.
- The error was in the newly invented CI tolerance, not in the governing equation.

### Correction

The independent-path agreement gate is now `1e-14 V` (10 fV), which remains much tighter than any experimental requirement while correctly accommodating the frozen decimal precision of the primary eV/K constant.

The CI source comments explicitly document this rationale so the tolerance cannot be mistaken for a measurement uncertainty.

### Provenance

Failing GitHub Actions run after the loader fix: `scientific-reproducibility` run `33003447141`.
