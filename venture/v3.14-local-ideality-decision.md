# v3.14 deployment decision — preserve curvature, not one ideality number

## Decision

Do not build the R2 mechanism gate around a single fitted ideality factor. Use a local `Voc`-versus-`ln(light intensity)` curve as the primary recombination diagnostic, with the existing 0.1–1 sun global slope retained only as a compact summary.

## Why this matters commercially

The intended open technology is a process-control system, not an academic fit parameter. A diagnostic that changes materially with an analyst-selected intensity window is a poor control-state variable. Preserving local curvature makes the metrology package more transferable between laboratories and reduces the risk that an apparent process improvement is actually a change in injection regime or contact/surface recombination.

## Capital consequence

This increment does not justify new hardware. It changes acquisition and analysis requirements only:

- retain enough log-spaced light-intensity points to support a seven-point local fit;
- retain a nine-point smoothing sensitivity where point density permits;
- publish the complete curve and uncertainty rather than one number;
- if local and global interpretations conflict, spend on measurement precision/density before proprietary material campaigns.

The incremental cost is therefore measurement time and analysis discipline, materially cheaper than a mistaken B0/B1/B2 mechanism campaign.

## Claim boundary

The local estimator is public metrology know-how, not core IP. The prospective open platform value remains the validated mapping from process state to physically meaningful loss state to useful electrical output, with conventional explanations actively tested.

## Release gate

No R2 H3/interface-recombination interpretation is promoted from exploratory status solely because a local ideality curve changes. It must agree with the preregistered FTPS/sensitive-EQE, EL/injection, temperature, and contact/transport discriminators.
