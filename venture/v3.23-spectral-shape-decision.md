# v3.23 deployment decision — spectral shape before mechanism

## Decision

Do not spend interpretation credibility on R2 `Voc`-intensity curvature until wavelength-resolved source-spectrum behavior has been checked across the full irradiance sweep.

The near-term facility requirement becomes:

1. record the same 17 intensity states used for `Voc`;
2. acquire wavelength-resolved source irradiance at those states;
3. provide reference-detector spectral responsivity;
4. provide R2 DUT EQE/spectral responsivity or an explicitly justified proxy;
5. run v3.23 before reading the mechanism-facing curvature result;
6. if mismatch/bias fails, repair/model the illumination system first.

## Why it changes deployment value

A broadband reference detector can report stable target irradiance while a multi-channel LED source, attenuation optic, lamp, or source temperature changes spectral shape. Because the DUT and reference detector have different spectral responsivities, that shape change can bend the DUT's effective `ln(Phi)` axis.

This is a cheap failure mode to test compared with fabricating more substrates or adding advanced spectroscopy. Detecting it early prevents false mechanism work and makes facility comparisons more transferable.

## Synthetic planning result

The committed synthetic stress case has only 0.318% maximum mismatch deviation yet creates a +0.001215 curvature bias on an explicitly synthetic `Delta_n=0.10` curve. At 4x the chosen synthetic spectral-shape distortion, the provisional 1% mismatch gate fails.

These values are software-test operating characteristics, not vendor/facility specifications.

## Capital implication

No new instrument purchase is authorized by this result. First preference is to use a cooperating facility's calibrated spectroradiometer and existing EQE/spectral-responsivity capability. An in-house spectroradiometer purchase should require demonstrated recurring external cost or scheduling friction plus a complete uncertainty/provenance plan.

## Open-source value

Publishing source spectra, responsivity curves, mismatch factors, covariance modes, and the exact curvature propagation makes inter-facility disagreements diagnosable instead of anecdotal. The method itself is established metrology; the public value is the executable integration with the R2 claim gate.

## Kill/narrow rule

If the R2 apparent curvature changes materially after wavelength-resolved mismatch correction, narrow the DUT-physics claim. If it disappears inside propagated spectral uncertainty, treat spectral/illumination behavior as a sufficient conventional explanation unless a prospective remeasurement under spectrally stable conditions restores the effect.
