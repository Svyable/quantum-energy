# v3.24 venture decision — randomize before mechanism

## Decision

Do not promote a monotonic R2 `Voc`-intensity curvature result to a confirmatory mechanism claim until acquisition-order confounding is independently challenged.

The low-cost next control is four complete randomized intensity blocks using the frozen v3.24 schedule and actual elapsed-time recording. This adds measurement time, not new capital equipment.

## Why it matters

The synthetic limiting case shows that only 0.5 mV peak-to-peak quadratic time dependence can create a false curvature of `0.0131`, already larger than the current 0.01 calibration-bias planning scale. Linear time drift alone is nearly harmless to curvature on the geometric grid, so a simple start/end anchor is not a complete discriminator for nonlinear conditioning.

These are synthetic software results, not observed R2 behavior.

## Capital / product implication

This gate increases expected value before proprietary-material spend because it tests an ordinary measurement confound with the existing source/DUT/electrical setup. A failed randomized-order check should redirect effort toward settling, thermal, contact, source-regulation, or device-history control instead of more mechanism modeling.

No procurement or manufacturing commitment is justified by v3.24.

## Claim boundary

Passing v3.24 supports only the adequacy of a smooth acquisition-time correction under the declared randomized design. It does not establish EPC, open-quantum transport, improved energy conversion, or commercial performance.

## Kill / narrow rule

If randomized-order drift-adjusted curvature differs materially from the monotonic result or cannot meet `u(Delta_n_curv)<=0.01` and residual SD `<=0.5 mV`, narrow the R2 curvature result to an acquisition-protocol-dependent observation. Do not use it to release the modern-OPV mechanism program until the temporal state model is repaired and prospectively retested.

## Best next action

Run the v3.24 schedule on a qualified R2 pixel under the same configuration as the standard monotonic sweep. Preserve both datasets and compare them before inspecting any mechanism label.
