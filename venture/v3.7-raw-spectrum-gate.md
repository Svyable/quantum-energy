# v3.7 deployment gate — raw-spectrum analysis integrity

## Program decision

Do **not** spend on additional low-temperature mechanism samples until the spectral-analysis chain recovers a known reference linewidth from a real facility's native raw files.

## Why

The program seeks meV-scale spectral discrimination. A wavelength/energy Jacobian error, background bias, detector nonlinearity, or calibration drift can create an apparent shift before any transport model is applied.

## Capital implication

Highest-value next spend is facility integration/reference qualification, not more substrates: obtain native wavelength calibration and detector-response files; acquire dark/background/reference spectra; validate raw-to-linewidth recovery and empirical repeatability; only then use measured linewidth SD in sample-size/recovery calculations.

No new instrument ownership is justified by a synthetic PASS.

## Open-source deployment value

The harness is hardware-modular. External labs can insert their own response curves, backgrounds, and reference spectra while retaining the same transformation/validation logic. Cross-facility disagreement can therefore be diagnosed at the raw-data level.

## Claim boundary

A synthetic pipeline PASS establishes software/numerical readiness only. It does not establish real facility precision, real R2 linewidth, static disorder, EPC, open-quantum transport, or useful electrical work.
