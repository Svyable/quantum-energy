# Venture Plan

## Company thesis

Build a **programmable open-quantum materials and process-control platform** for ambient excitation/charge transport. The near-term wedge is organic-photovoltaic loss control and manufacturing intelligence; the long-term optionality includes polaritonic/quantum-photonic transport and nonlinear devices.

The company should not initially be presented as a universal room-temperature quantum-computing company or as a utility-scale PV manufacturer.

## Commercial sequencing

### Stage 0 — prediction and metrology
- Validate optical/TMM and open-system models against published benchmarks.
- Qualify absolute-EL / sensitive-EQE metrology to ≤10 mV equivalent ΔVnr uncertainty.
- Build and qualify R2 weak-EL transfer standard.

### Stage 1 — mechanism control
- Validate modern OPV interface/EPC causal chain in D18/PY-IT/eC9.
- Require prospective model predictions and blinded analysis.
- Kill/narrow the mechanism claim if morphology, contacts, injection artifacts, or ordinary disorder explain the result.

### Stage 2 — useful electrical work
- ≥5% relative stabilized Pmax improvement across ≥3 lots.
- No unacceptable accelerated-aging penalty.
- Demonstrate that the effect is not limited to one composition.

### Stage 3 — process-control moat
- Translate expensive mechanism observables into a cheaper optical/process soft sensor.
- Validate prospective out-of-substrate prediction.
- Build bounded recipe-control logic with explicit out-of-domain detection and periodic absolute-EL/FTPS audit.

### Stage 4 — cavity / polaritonic overlay
Only after the interface/EPC program passes useful-work and durability gates, test whether cavity/light–matter engineering provides additional benefit. Cavity coupling is not assumed beneficial; it can also slow charge transfer or add optical loss.

### Stage 5 — scale / licensing / productization
Preferred first business model: co-development, materials/process IP licensing, and design-rule/data packages for OPV materials/device developers, rather than owning module manufacturing immediately.

## Moat stack

Potential defensibility comes from the combined stack rather than any single published material:

1. measured interface/EPC state definition,
2. process recipe → latent-state model,
3. prospective latent-state → electrical-output prediction,
4. low-cost inline proxy / soft sensor,
5. bounded controller and process window,
6. multi-material calibration dataset,
7. reliability and scale-transfer rules,
8. potentially later joint cavity + interface/EPC optimization.

## IP boundaries

Crowded/prior-art territory that should not be claimed broadly:
- generic strong-coupling OPVs,
- generic cavity-mediated energy transfer,
- generic LiF/TPD interface or FRET behavior,
- generic morphology optimization,
- generic ternary/guest-additive OPVs,
- generic suppression of electron–phonon coupling,
- generic UV-vis or ellipsometry process monitoring.

White space to investigate, subject to formal prior-art/FTO review:
- manufacturing method that targets a measured EPC/reorganization/interface-population endpoint,
- calibrated process-to-latent-state-to-Pmax control law,
- cross-material prospective prediction using the same model form,
- inline soft-sensor + sparse quantum-loss audit architecture,
- joint cavity/EPC/sink co-design after useful-work validation.

## Capital logic

Use staged evidence gates rather than calendar milestones.

Planning ranges developed so far (not vendor quotes):
- model / optical calibration: ~$25k–$75k
- transport P0: ~$150k–$400k
- electrical P1 / modern-OPV campaigns: hundreds of thousands depending external spectroscopy/fabrication
- external AT-04 qualification: roughly tens of thousands before in-house capex
- full in-house temperature-dependent absolute-EL station: defer; planning scale ~$80k–$250k
- proprietary interface/EPC validation and multi-lot useful-work bridge: ~$0.4M–$1.5M class depending facility model
- 1–10 cm² scale demonstrator: later million-dollar-class program only after causal/useful-work gates

## Investor narrative

**Before mechanism proof:**
We are testing whether measurable open-system/interface variables can be engineered as design variables for energy conversion.

**After metrology + causal proof:**
We prospectively predict a microscopic loss variable and verify its electrical consequence with independent optical/electrical measurements.

**After useful-work proof:**
We can manufactureably move that state and obtain reproducible stabilized power improvement across lots.

**After soft-sensor/generalization proof:**
We have a predictive process-control engine rather than a one-off chemistry optimization.

## Kill / narrow rules

- If the claimed environmental/interface effect disappears after absorption, morphology, electrostatic, injection, or dark-transport controls, do not call it open-quantum/EPC mechanism evidence.
- If ΔVnr cannot be measured with sufficient precision, redesign metrology before proprietary materials spend.
- If voltage-loss improvement does not translate to Pmax, keep it as mechanism science rather than product claim.
- If the effect cannot transfer to a second material system without changing the model form, narrow the platform/IP claim.
- If reliability or scale destroys the effect, stop product-scale claims until the process is redesigned.

## Data-room principles

Maintain immutable/raw and processed separation, versioned model hashes, preregistration records, fabrication travelers, calibration records, negative/null results, deviations, IP claim charts, EHS/SDS records, and a claim-to-evidence matrix for investor materials.
