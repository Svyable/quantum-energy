# v3.71 venture decision — design for graceful degradation, not one-path perfection

## Decision

Add **mechanism redundancy** to the long-term platform objective.

A deployable process should not only maximize nominal stabilized Pmax. Where physically possible, it should also avoid a single microscopic generation pathway becoming the unique point of failure under morphology drift, interface disorder, scale variation, ageing, or future mechanical deformation.

## Why this creates new value

The existing program already treats environment/interface design, field robustness, transport, durability and scale as separate gates. v3.71 adds a systems-level synthesis:

**multiple partially independent generation routes may provide graceful degradation if their perturbation sensitivities differ.**

This could make the eventual controller optimize a robustness surface rather than one nominal recipe.

## Business / deployment implications if validated

Potential advantages include:

- wider manufacturing process windows;
- less catastrophic sensitivity to local morphology/interface defects;
- better retention under thermal/light ageing;
- a principled route toward mechanically compliant/flexible variants;
- more transferable control rules across coating thickness and area scale.

None of these advantages is currently demonstrated for D18/PY-IT/eC9.

## Required decision metric

Normalized retention alone is not enough. Any resilience candidate must be evaluated jointly on:

- absolute stabilized Pmax before perturbation;
- absolute stabilized Pmax after perturbation;
- field-generation retention;
- transport/contact retention;
- morphology/packing state;
- durability and manufacturability;
- independent-lot reproducibility.

A low-performing device that merely degrades slowly is not a platform win.

## Kill rule

Retire the mechanism-redundancy interpretation for a given design if the apparent robustness disappears after absorption/contact/transport normalization, if the secondary route is not independently more robust, or if absolute stabilized useful work is worse.

## Capital rule

Do not add new hardware solely for this concept yet. First exploit already-planned donor-free controls, TDCF/bias-dependent PL, stabilized Pmax, durability stresses and morphology/transport witnesses. Only buy or build specialized strain/flexible-device capability if those data show that route redundancy is real and worth pursuing.
