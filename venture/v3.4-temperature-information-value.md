# v3.4 deployment / capital note — low-temperature information before extra substrates

## Decision

Do **not** automatically expand the R2 mechanism audit from five to nine substrates yet.

First qualify whether 120/150 K CT-linewidth measurements are stable and precise on the non-proprietary reference stack. Under the v3.4 synthetic generator, this added observable changes the information content enough that seven substrates cross the existing >=80% per-class synthetic recovery gate, while nine retain a stronger publication margin.

## Why this is capital-efficient

The next spend should retire the uncertainty that actually controls sample count:

1. Can the weak-EL reference remain functional and in a comparable injection regime at 120/150 K?
2. What is the empirical CT-linewidth repeatability in meV under those conditions?
3. Does a one-mode/fixed-vibronic-prior model describe the data adequately, or do multiple modes/model ambiguity dominate?

If the empirical linewidth noise and model adequacy are favorable, a seven-substrate confirmatory design may be sufficient. If not, the program keeps N=9 or changes the discriminator. The synthetic calculation therefore changes **sequencing**, not yet the committed physical sample count.

## Open-source/public-benefit framing

The relevant public good is not a claim that low-temperature spectroscopy is proprietary. The reusable contribution is:

- an explicit physical model and limiting-case check;
- a machine-readable synthetic recovery study;
- a predeclared rule linking measurement precision to sample-count decisions;
- publication of null/failed low-temperature feasibility results if they occur.

Any lab should be able to replace the synthetic linewidth-noise assumption with its own reference measurement and rerun the same recovery code.

## Cost model

No vendor quote is introduced in v3.4. The only decision-driving cost relation is qualitative:

- low-temperature feasibility reuses the temperature-dependent metrology architecture already contemplated for AT-04;
- extra independent substrates add fabrication and characterization burden;
- therefore measuring the information value of the low-temperature observable before fabricating four additional confirmatory substrates is rational when the feasibility test is materially cheaper than the full extra-substrate program.

That inequality must be revisited with actual facility quotes; no numerical savings are claimed here.

## Risk / stop rules

- If 120/150 K produces irreversible R2 changes, abandon this discriminator on R2.
- If CT-linewidth repeatability is too poor to improve synthetic recovery, retain N=9 or seek another orthogonal observable.
- If multiple-mode fits are non-identifiable, do not interpret a fitted static intercept as static DOS disorder.
- If low-temperature injection materially changes state occupancy, classify the result as a measurement-state problem unless reciprocity/control analysis shows otherwise.

## Next financing / deployment evidence

The next evidence packet should be a **low-temperature feasibility certificate** containing device survival, DUT temperature accuracy, linewidth repeatability, injection dependence, SNR/background, fit/model comparison, and the rerun synthetic confusion matrix using empirical noise.
