# v3.17 Facility Qualification Decision

## Decision

Treat facility measurement qualification as a machine-readable stage gate before spending scarce R2 samples on confirmatory mechanism interpretation.

## Operational consequence

A facility export now receives one of three states:

- `PASS`: all frozen measurement-path gates evaluate and pass;
- `INCOMPLETE`: required calibration/spectral/temperature/precision information is missing;
- `FAIL`: at least one frozen gate fails.

Only `PASS` permits the v3.15 curvature observable to advance as a qualified measurement-path result. This does not make the mechanism claim confirmatory; independent substrate count and H1–H4 discrimination gates remain separate.

## Capital implication

The cheapest failure is a calibration/metadata failure discovered before a proprietary or multi-lot device campaign. Therefore facility partners should be asked to export the v3.17 schema and run the CLI on a reference before B0/B1/B2 release or expanded R2 mechanism sampling.

## Open-source benefit

The qualification certificate is facility-neutral and uses only Python standard-library code. Collaborating labs can inspect the equations, thresholds, raw inputs, covariance-group labels, and exact failure reasons without proprietary software.

## Boundary

No vendor capability, facility performance, or energy-conversion improvement is claimed by this increment. The clean dataset is synthetic.
