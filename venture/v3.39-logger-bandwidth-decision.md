# Venture decision gate — v3.39 logger/package temporal fidelity

Do not treat an inexpensive environmental logger as adequate merely because it can export a complete CSV. Before paid multi-facility R2 transfer work, qualify one representative logger/carrier/package on dummies against faster calibrated references.

## Spend/interpretation gate

Proceed to qualified-primary transfer only if the configuration is `QUALIFIED_FOR_DECLARED_BANDWIDTH` and the resulting configuration-specific maximum gap is implemented in the transfer logging workflow. `INCOMPLETE` or `FAIL_BANDWIDTH` blocks using that logger record to rule out shipping/environmental state change.

The provisional 5-samples-per-time-constant and 0.90 acceleration peak-capture thresholds are engineering planning assumptions. They are not vendor requirements, regulatory limits, or evidence that the device is protected from the measured exposure.

## Value

This is a low-cost falsification step: it can prevent facility spend from generating ambiguous cross-site disagreement whose simplest explanation is an under-resolved transfer excursion. Negative qualification results remain useful because they identify the minimum logger/package bandwidth needed before the more expensive campaign.
