# Venture decision gate — v3.37 reciprocity concordance

The venture program should not spend mechanism-facing or proprietary-material capital on an R2/AT-04 measurement configuration that cannot pass the existing direct-vs-reciprocity `Delta V_nr` concordance screen with complete provenance.

## Gate

A configuration is eligible for downstream mechanism-facing use only when paired direct and reciprocity estimates are complete, configuration-matched, QC-valid, independently traceable to raw/minimally processed data and analysis commits, and satisfy the inherited planning criterion `|Delta V_nr,direct - Delta V_nr,reciprocity| <= 20 mV`.

`INCOMPLETE` is not equivalent to pass, and uncertainty is not used to relax the 20 mV screen. A failed or incomplete screen should trigger metrology diagnosis before additional proprietary fabrication or facility spend.

## Commercial interpretation boundary

Passing v3.37 does not establish device efficiency, facility equivalence, EPC control, open-quantum transport, or product readiness. It only reduces one avoidable diligence risk: two nominally related voltage-loss analysis paths disagreeing without a visible audit trail.

## Cost logic

No new cost estimate or vendor quote is introduced. The economic value of the gate is procedural: detect calibration/analysis incompatibility before higher-cost mechanism and materials campaigns.
