# v3.5 — Low-temperature information-value gate

## Capital/deployment change

Do **not** commit to a 120 K-capable mechanism campaign merely because the synthetic classifier benefits from the extra point.

The staged open-source deployment rule is now:

1. qualify 150 K on a non-proprietary PM6:Y6-class reference;
2. attempt 120 K only if 150 K preserves the relevant device operating regime and the measurement remains injection/thermal/SNR qualified;
3. rerun the public H1–H4 synthetic recovery model using the measured linewidth uncertainty and actual usable temperature grid;
4. only then choose the confirmatory substrate count or a different discriminator.

## Why this is higher-value than adding samples immediately

The v3.4 N=7/N=9 sample-size result depends on a synthetic 2 meV linewidth-noise assumption and on 120/150 K being valid observations of the same mechanism. Published PM6:Y6 evidence makes 150 K plausible but warns that below ~150 K extraction/recombination can change. Therefore measurement-regime validation has higher information value than automatically buying more devices.

No numerical cost saving is claimed because no vendor/facility quote is attached to this decision.

## Public-benefit outcome

A failed 120 K qualification is useful: it would publish a clear boundary on when this PM6:Y6 reference can and cannot support low-temperature mechanism inference, preventing other labs from mistaking cryogenic transport artifacts for energetic-disorder physics.

## Open-source publication packet if measured

Publish:
- all temperature/injection raw spectra;
- stage and DUT temperature streams;
- electrical power at each injection point;
- dark/background frames;
- photovoltaic EQE before/during/after cycle where practical;
- linewidth extraction code and fit windows;
- every valid reference device, including failures;
- model-comparison and synthetic-recovery rerun using empirical noise.
