# v3.6 Low-Temperature Execution / Capital Gate

## Program delta

The low-temperature discriminator is now an **execution-and-information gate**, not a cryostat procurement program.

Existing commercial/core platforms already cover the 120–330 K range; the unresolved risk is mounted-device temperature fidelity, self-heating, weak-signal SNR, and empirical linewidth repeatability. Accordingly, no new in-house cryostat purchase is released by v3.6.

## Capital logic

Spend sequence:

1. qualify the selected external/core setup with a non-proprietary R2/reference article;
2. measure actual DUT-stage gradients, self-heating, spectral SNR, and linewidth repeatability at 150 K;
3. attempt 120 K only if 150 K passes;
4. feed the measured usable temperature grid and linewidth SD into the public recovery code;
5. only then choose N=5/7/9 or abandon the low-temperature discriminator.

Any service-cost estimate remains **RFQ required**. Prior broad spectroscopy/core-service allowances remain planning values, not quotes.

## Deployment relevance

This measurement is deliberately an offline mechanism audit. It is **not** intended as an inline manufacturing sensor. Its value is to validate or reject the latent-state physics that a later cheap UV-vis/optical proxy would estimate at production speed.

Thus the scalable architecture remains:

`inline optical proxy -> latent state estimate -> bounded process correction`

with sparse FTPS/EL/low-temperature audits as ground truth.

## Open-source value

The v3.6 package publishes:

- device-side mechanical interface requirements;
- raw-data schema;
- sensor/heating acceptance logic;
- explicit conventional failure modes;
- executable code that converts measured uncertainty into a synthetic H1-H4 sample-size gate.

A laboratory can therefore reproduce the decision even if it uses a different cryostat vendor.

## Kill / narrow rules

- If 150 K changes device operating regime or fails recovery/reversibility, do not use 120 K for mechanism classification.
- If linewidth SD is >2 meV, retire v3.4's nominal sample-size result and rerun the recovery decision with measured noise.
- If no feasible N/design crosses the >=80% synthetic recovery gate after measured uncertainty is inserted, retain low-temperature spectroscopy as descriptive science only.
- If low-temperature data add little classification information beyond room-temperature FTPS/EL/Voc-intensity measurements, remove the low-temperature branch from the near-term program.

## Investor / public-benefit narrative

The project is spending first on **information quality rather than hardware ownership**. The useful milestone is not 'we bought a cryostat'; it is 'we measured whether low-temperature data materially improve mechanism identifiability, with public code and stop rules.'
