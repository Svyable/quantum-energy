# v3.28 facility audit — deployment decision

## Decision

**Do not select or schedule a full R2 facility campaign from public capability pages alone.** Proceed to standardized direct confirmation using the same eight questions in `technical/r2-candidate-facility-audit-v3.28.md`.

## Why this is high-value

The merged v3.27 contract made facility readiness machine-readable. v3.28 tests that contract against real public evidence and exposes the remaining integration burden before samples, travel, or metrology spend are committed.

## Current candidate evidence state

- NREL PVDPC: strongest public support in reference calibration/traceability, spectral characterization, and linearity; custom repeated-session/temporal/randomized workflow remains unconfirmed.
- Fraunhofer ISE CalLab PV Cells: strong public support in accredited calibration and broad spectral responsivity including organic/thin-film cells; several custom R2 workflow requirements remain unconfirmed.
- IPVF: strong public support for accessible EQE/IQE, FTPS, solar-simulator, and custom optical-bench infrastructure; published simulator intensity range does not span the frozen 0.05–2 sun R2 range, and multiple custom requirements remain unconfirmed.

These statements are evidence summaries, not comparative quality judgments.

## Gate to spend

Before committing the full campaign, require written confirmation of every decision-critical capability, the raw/provenance return format, and configuration continuity. Any unresolved item remains `INCOMPLETE`.

If a multi-facility split is unavoidable, require a bridge measurement using the same stable transfer artifact/configuration overlap before combining facility-specific uncertainty components. Do not treat measurements from different facilities as exchangeable replicates by default.

## Commercial implication

The near-term bottleneck is experimental integration rather than another synthetic mechanism model. A facility that can return traceable raw data and preserve prospective analysis boundaries is more valuable to the current stage than a broader instrument list without the required provenance/custom workflow.
